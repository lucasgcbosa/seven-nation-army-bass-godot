# Seven Nation Army Bass - Godot Project

## Project Description

This project is my individual instrument contribution for our group Godot music project.  
Each member of the group created a different virtual instrument in Godot, and my chosen instrument was the bass.

My project is based on the bass line from **Seven Nation Army**. The Godot file includes an interactive bass system where the user can play bass notes using keyboard inputs. The project also includes a performance mode that automatically plays the Seven Nation Army bass sequence.

The bass reacts visually when notes are played, including string vibration effects and stage light changes. This makes the project work not only as a sound generator, but also as a simple interactive music visualizer.

## Features

- Interactive bass instrument made in Godot
- Keyboard-controlled bass notes
- Seven Nation Army bass sequence
- Practice mode for manual playing
- Performance mode for automatic playback
- Visual string vibration when notes are played
- Stage lights that react to the music
- Distortion-style bass sound effect

## How to Run

1. Download or clone this repository.
2. Open Godot.
3. Import the project using the `project.godot` file.
4. Open the main scene.
5. Run the project.
6. Use the keyboard controls to play the bass or switch to performance mode.
